What the platform is doing

1 · White-labeled entry

One agent config, themed per org via UiConfig (colour, avatar, launcher). The link arrives on WhatsApp/SMS from the ATS. Language picked here sets the conversation locale.

UiConfigEmbed / direct linklanguage[]

2 · Consent first, then confirm-don't-ask

Itemized, plain-language consent before any data is collected (DPDP Rules 2025 / PDPA), logged with a timestamp. Then the agent shows what it already knows and asks the candidate to confirm, not retype. Research: chat-native application steps convert at ~92% vs ~20% for form portals (Paradox).

CHAT_AGENT stepsConsent audit eventForm widget

3 · Document capture + OCR

Native camera capture with client-side quality checks, then OCR extracts fields. Candidate verifies extracted values instead of typing them. ID number is masked by default. In India this stage swaps to DigiLocker / Aadhaar eKYC fetch — no photo at all.

ImageCapture widgetTOOL step → OCRConfirmation widget

4 · Liveness + face match

Passive liveness with an oval guide — no "turn your head" gymnastics. Face is matched against the ID photo. Biometric consent is explicit and logged as a guardrail event.

ImageCapture (selfie)Guardrail eventsSessionMediaConfig

5 · Background checks — async

Consent first (PDPA-compliant, purpose-scoped). Checks dispatch to a WORKFLOW_AGENT pipeline and run in the background — the conversation keeps moving. Slow checks never block the candidate.

WORKFLOW_AGENT DAGWRITE step + outboxWAIT step (callback)

6 · AI screening interview

Structured questions scored against a rubric — voice or text, candidate's choice, in the same thread, no login (login-gated video interviews lose 20-25% of candidates). Chat-format interviews reach ~75% completion (Sapia), and showing candidates why they scored well ties to large retention gains. Human makes the call, not the model.

LLM step + rubricVoiceConfig / STTScoreCard widget

7 · Training reels, in chat

Skilling LMS reels open inside the conversation — vertical video with the reels-MCQ QUESTION frame. Chat-delivered microlearning reaches ~85% completion vs 20–30% for a separate LMS. Post-hire, spaced reels keep feeding a readiness score to ops.

Skilling reels + MCQ frameMcq widgetLMS content API

8 · Done — verified crew ID

Completion card with digital crew ID. One check may still run in the background — status is pushed via WhatsApp when it lands. Offer→Day-1 is its own tracked funnel stage with nudges: post-offer ghosting is the costliest drop-off in frontline hiring (compressing the window cut attrition ~62% in one study).
